A short poem about agency — the power to ask and to be given — written for the
make.fun competition "The poem about permission".

The poem: a caregiver asks before lifting their mother. Her yes does not hand
over control — she still decides how she is touched. Asking permission, the
poem says, is not surrender; the one who says yes still holds the reins.

## Run

```sh
node main.ts
```

This writes the poem to `/output/entry.txt` (UTF-8, 1–280 characters).
No network is used.
